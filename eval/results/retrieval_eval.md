## Method notes and limits

- *The code-files-only keyword baseline was added after a code review of this script found the specified baseline spends top-10 slots on `.md`/`.json` files that can never be relevant (113 of 350 slots were `.md`). The specified baseline is reported unchanged; this row is supplementary.
- Precision@10 divides by 10 even when fewer files are returned; with ~1–3 relevant files per commit its ceiling is low by construction.
- Ground truth is every modified source file, including incidental edits a reviewer might not call "relevant"; that biases recall down. Deleted files are not scored.
- The leakage flag is a regex for `name.ext` tokens; it also flags names like `Node.js` (conservative).
- Commits are sampled from `git log HEAD` of each repo; replay the exact list with `--commits`.
- The no-import-graph ablation monkeypatches `retriever._import_edges` to return `{}` inside the eval process only; `retriever.py` is unchanged.
